
### 1. Dependências de desenvolvimento (`devDependencies`)

- `electron-builder`: Ferramenta para compilar o app
- `@electron/rebuild`: Reconstrói módulos nativos

### 2. Configuração do electron-builder (`build`)
Como o aplicativo será compilado:
- `appId`: Identificador único do app
- `asar`: Empacota o app em formato ASAR
- `win/target`: Formato do arquivo para Windows
